# Fixture 04 — Clone de template MLM (fork Etherscan) avec token concentré

## Faits (intake)
- Nom : MetaForce X, contrat vérifié sur BscScan
- « Similar Contracts » Etherscan : match quasi identique à un template d'affiliation déjà répertorié (cosmétique près : nom, logo)
- R&D : aucune innovation propriétaire ; roadmap technique non livrée
- Tokenomics : 70% de l'allocation initiale détenue par une poignée de wallets proches du deployer
- Structuration : clé admin unique (pause, mint, withdraw), pas de timelock/multisig
- Affiliation : matrice à rangs, gains concentrés sur le top des recruteurs

## Attendu
- **R&D 🔴** : fork quasi identique d'un template MLM répertorié (via Similar Contracts).
- **Structuration 🔴** : pouvoir technique (clé unique) + pouvoir économique (token concentré) + arbre d'affiliation concentré.
- Tokenomics traité sous 3 angles NON redondants : concentration → Structuration (score), originalité → R&D (score), soutenabilité → Finance (mention croisée sans re-scorer).

## Garde contre
Rater un copier-coller de contrat pyramidal. Vérifie le gate #3 (tokenomics non double-scoré entre Finance/R&D/Structuration).
